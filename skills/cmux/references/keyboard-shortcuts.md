# cmux Keyboard Shortcuts

## Workspaces

Workspaces live in the sidebar. Each workspace has its own panes and surfaces.

| Action | Shortcut |
|--------|----------|
| New workspace | ⌘+N |
| Jump to workspace 1–8 | ⌘+1–8 |
| Jump to last workspace | ⌘+9 |
| Next workspace | ⌃+⌘+] |
| Previous workspace | ⌃+⌘+[ |
| Close workspace | ⌘+⇧+W |
| Rename workspace | ⌘+⇧+R |
| Toggle sidebar | ⌘+B |

## Surfaces

Surfaces are tabs inside a pane.

| Action | Shortcut |
|--------|----------|
| New surface | ⌘+T |
| Next surface | ⌘+⇧+] |
| Previous surface | ⌘+⇧+[ |
| Next surface (alt) | ⌃+Tab |
| Previous surface (alt) | ⌃+⇧+Tab |
| Jump to surface 1–8 | ⌃+1–8 |
| Jump to last surface | ⌃+9 |
| Close surface | ⌘+W |

## Split Panes

| Action | Shortcut |
|--------|----------|
| Split right | ⌘+D |
| Split down | ⌘+⇧+D |
| Focus pane directionally | ⌥+⌘+←/→/↑/↓ |
| Flash focused panel | ⌘+⇧+H |

|--------|----------|

| Focus address bar | ⌘+L |
| Back | ⌘+[ |
| Forward | ⌘+] |

| Toggle Developer Tools | ⌥+⌘+I |

| Action | Shortcut |
|--------|----------|
